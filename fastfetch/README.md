# UNION FASTFETCH CONFIGURATION

To use a custom fastfetch configuration with the UNION theme:

## Installation

```bash
mkdir -p ~/.config/fastfetch
cp fastfetch/config.jsonc ~/.config/fastfetch/
```

## Usage

```bash
fastfetch --config ~/.config/fastfetch/config.jsonc
```

## Custom Configuration

The UNION fastfetch configuration displays:

- Custom ASCII art logo on the left
- System information on the right
- Fictional facility metadata (clearly marked)

See the main README.md for more information.
