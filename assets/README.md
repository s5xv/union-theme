# UNION ASSETS

This directory contains additional assets for the UNION theme.

## Contents

- Logos and icons
- Additional ASCII art
- Template files
- Documentation images

## Adding Assets

Place any additional theme assets in this directory. They will not be installed by the installer but can be referenced manually.

## Logo Formats

If you create logo files, provide them in:

- SVG — Vector format for UI elements
- PNG — Raster format with transparency
- TXT — ASCII art versions (see `ascii/` directory)
