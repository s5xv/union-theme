# UNION WALLPAPERS

Place your wallpaper images in this directory.

## Expected Files

| Filename | Workspace | Description |
|----------|-----------|-------------|
| `archive.jpg` | 1 - ARCHIVE | Dark, institutional, archival aesthetic |
| `research.jpg` | 2 - RESEARCH | Scientific laboratory, blue tones |
| `orbital.jpg` | 3 - ORBITAL | Space station, Earth observation |
| `lunar.jpg` | 4 - LUNAR | Moon surface, lunar base |
| `deep-space.jpg` | 5 - DEEP SPACE | Deep space, nebula, stars |
| `control.jpg` | 6 - CONTROL | Mission control, instrumentation |

## Recommended Image Sources

- NASA Image and Video Library (images.nasa.gov)
- ESA Image Archive
- Unsplash (free to use)
- Pexels (free to use)

## Image Specifications

- Resolution: 1920x1080 or higher
- Format: JPEG or PNG
- File size: Under 5MB recommended

## Automatic Setup

Run the wallpaper initialization script:

```bash
union-wallpaper --init
```

This will create placeholder images if they don't exist.

## Custom Wallpapers

You can use any images you like. The filenames must match the expected names above for auto-switching to work.
